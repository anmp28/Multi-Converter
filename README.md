⚡ MultiConverterMultiConverter is an all-in-one, open-source file conversion suite created by Ancor Montalvo. It processes files 100% locally in your browser (client-side), ensuring lightning-fast performance, zero server queue time, total privacy, and full compatibility with GitHub Pages.🔗 Official Repository: https://github.com/anmp28/Multi-Converter🌐 Language Navigation / Navegación de Idioma🇬🇧 English Readme🇪🇸 Lea el Readme en Español🇬🇧 English✨ Key Features🔒 100% Privacy (Zero-Server): Your files never leave your computer. Everything is processed locally using browser APIs and WebAssembly.⚡ Fast & Free: No upload size limits, no queue times, no user registration, and no paywalls.🌐 GitHub Pages Ready: Pure static web application built without any heavy server backends.🎨 Modern Interface: Sleek, responsive design with Dark Mode, smooth animations, and drag-and-drop file uploaders.🛠️ Supported File Types & Conversions📄 Documents & Office PresentationsFormats: PDF, DOCX (Word), PPTX (PowerPoint), XLSX / CSV (Excel), EPUB, RTF, TXT, HTML, Markdown (.md).Tools:PDF ↔ Images (PNG/JPG to PDF and PDF page extraction to images).DOCX / PPTX / XLSX text extraction and preview generation.Markdown / HTML to PDF & DOCX export.E-book conversion (EPUB to PDF/TXT).Data conversion (JSON ↔ CSV ↔ XML ↔ YAML ↔ XLSX).🖼️ Images & GraphicsFormats: PNG, JPG / JPEG, WebP, SVG, GIF, BMP, ICO (Favicon generation), TIFF, AVIF, PSD, EPS.Tools: Format conversion, batch image compression, dynamic resizing, vector tracing (raster to SVG), background removal, and .ico bundle generator.🎵 Audio & VideoFormats: MP3, WAV, OGG, WebM, AAC, FLAC, MP4, AVI, MOV, MKV.Tools: Video to GIF converter, audio extraction from video streams, audio trimming, channel splitting, and bitrate adjustment via WebAudio API & FFmpeg.wasm.📦 Archives & CompressionFormats: ZIP, TAR, GZ, 7Z, RAR (extraction).Tools: Extract contents directly in browser memory, build custom ZIP archives, and compress multiple documents or images in batch.🌐 Deployment on GitHub PagesTo deploy MultiConverter on your own GitHub account:Go to repository Settings $\rightarrow$ Pages.Under Build and deployment, set Source to Deploy from a branch.Select the main branch (folder /root) and click Save.🤝 ContributingContributions are welcome!Fork
