# ⚡ MultiConverter

**MultiConverter** is an all-in-one, open-source file conversion suite created by **Ancor Montalvo**. It processes files 100% locally in your browser (client-side), ensuring lightning-fast performance, zero server queue time, total privacy, and full compatibility with **GitHub Pages**.

🔗 **Official Repository:** <https://github.com/anmp28/Multi-Converter>

## 🇬🇧 English

### ✨ Key Features

* 🔒 **100% Privacy (Zero-Server):** Your files never leave your computer. Everything is processed locally using browser APIs and WebAssembly.
* ⚡ **Fast & Free:** No upload size limits, no queue times, no user registration, and no paywalls.
* 🌐 **GitHub Pages Ready:** Pure static web application built without any heavy server backends.
* 🎨 **Modern Interface:** Sleek, responsive design with Dark Mode, smooth animations, and drag-and-drop file uploaders.

### 🛠️ Supported File Types & Conversions

#### 📄 Documents & Office Presentations
* **Formats:** PDF, DOCX (Word), PPTX (PowerPoint), XLSX / CSV (Excel), EPUB, RTF, TXT, HTML, Markdown (.md).
* **Tools:** 
  * PDF ↔ Images (PNG/JPG to PDF and PDF page extraction to images).
  * DOCX / PPTX / XLSX text extraction and preview generation.
  * Markdown / HTML to PDF & DOCX export.
  * E-book conversion (EPUB to PDF/TXT).
  * Data conversion (JSON ↔ CSV ↔ XML ↔ YAML ↔ XLSX).

#### 🖼️ Images & Graphics
* **Formats:** PNG, JPG / JPEG, WebP, SVG, GIF, BMP, ICO (Favicon generation), TIFF, AVIF, PSD, EPS.
* **Tools:** Format conversion, batch image compression, dynamic resizing, vector tracing (raster to SVG), background removal, and `.ico` bundle generator.

#### 🎵 Audio & Video
* **Formats:** MP3, WAV, OGG, WebM, AAC, FLAC, MP4, AVI, MOV, MKV.
* **Tools:** Video to GIF converter, audio extraction from video streams, audio trimming, channel splitting, and bitrate adjustment via WebAudio API & FFmpeg.wasm.

#### 📦 Archives & Compression
* **Formats:** ZIP, TAR, GZ, 7Z, RAR (extraction).
* **Tools:** Extract contents directly in browser memory, build custom ZIP archives, and compress multiple documents or images in batch.

### 🌐 Deployment on GitHub Pages

To deploy **MultiConverter** on your own GitHub account:

1. Go to repository **Settings** $\rightarrow$ **Pages**.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Select the `main` branch (folder `/root`) and click **Save**.

## 🇪🇸 Español

### ✨ Características Principales

* 🔒 **100% Privacidad (Sin Servidor):** Tus archivos nunca salen de tu dispositivo. Todo el procesamiento ocurre localmente mediante APIs web del navegador y WebAssembly.
* ⚡ **Rápido y Gratuito:** Sin límites de peso, sin tiempos de espera, sin registros y totalmente gratis.
* 🌐 **Listo para GitHub Pages:** Aplicación web estática pura construida sin necesidad de servidores backend.
* 🎨 **Interfaz Moderna:** Diseño elegante, responsivo, con modo oscuro, animaciones fluidas y soporte para arrastrar y soltar (Drag & Drop).

### 🛠️ Tipos de Archivos y Conversiones Soportadas

#### 📄 Documentos y Presentaciones de Oficina
* **Formatos:** PDF, DOCX (Word), PPTX (PowerPoint), XLSX / CSV (Excel), EPUB, RTF, TXT, HTML, Markdown (.md).
* **Herramientas:** 
  * PDF ↔ Imágenes (PNG/JPG a PDF y extracción de páginas PDF a imagen).
  * Extracción de texto y vista previa para DOCX, PPTX y XLSX.
  * Exportación de Markdown / HTML a PDF y DOCX.
  * Conversión de libros electrónicos (EPUB a PDF/TXT).
  * Conversión de datos estructurados (JSON ↔ CSV ↔ XML ↔ YAML ↔ XLSX).

#### 🖼️ Imágenes y Gráficos
* **Formatos:** PNG, JPG / JPEG, WebP, SVG, GIF, BMP, ICO (Favicons), TIFF, AVIF, PSD, EPS.
* **Herramientas:** Conversión de formato, compresión por lotes, redimensionado, vectorización (imagen a SVG), eliminación de fondos y creador de favicons `.ico`.

#### 🎵 Audio y Video
* **Formatos:** MP3, WAV, OGG, WebM, AAC, FLAC, MP4, AVI, MOV, MKV.
* **Herramientas:** Conversor de vídeo a GIF, extracción de pistas de audio desde vídeo, recorte de audio y ajuste de bitrate mediante WebAudio API y FFmpeg.wasm.

#### 📦 Archivos Comprimidos
* **Formatos:** ZIP, TAR, GZ, 7Z, RAR (extracción).
* **Herramientas:** Descompresión directa en la memoria local, extracción de ficheros individuales y empaquetado por lotes en archivos `.zip`.
